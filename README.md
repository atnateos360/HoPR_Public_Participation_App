"# HoPR Public Participation App

This repository contains a static prototype for the HoPR public participation experience: a mobile-first civic engagement app designed to help citizens discover parliamentary issues, follow consultations, and connect with their elected representatives.

## Included prototype

- `HoPR_App_Prototype.html` – a standalone HTML/CSS prototype of the app interface, including onboarding, issue discovery, consultation flows, community updates, and representative matching.

## Running the prototype

Because the app is a single-page static prototype, you can open `HoPR_App_Prototype.html` directly in a browser.

If you prefer serving it locally instead:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/HoPR_App_Prototype.html` in your browser.

## Project purpose

The prototype explores how a public participation platform can:

- make parliamentary business understandable to everyday citizens
- highlight current consultations and policy priorities
- help users explore issues by topic and location
- connect people with relevant representatives or MPs
- support structured public feedback and participation signals

## Notes

This is a design prototype rather than a full production application, so it focuses on interaction flow, visual language, and user experience exploration."
